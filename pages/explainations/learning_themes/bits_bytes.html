Zahlensysteme & Datenrepräsentation

Bits, Bytes und Stellenwerte.

Ein Computer kennt nur zwei Zustände. Aus diesen Nullen und Einsen entsteht jede Zahl.

01

Grundlagen

Alles, was ein Computer speichert, besteht aus Nullen und Einsen. Damit man mit diesen langen Kombinationen arbeiten kann, werden sie in feste Einheiten gruppiert: Bit und Byte. Ein Byte ist dabei einfach eine Gruppe von acht Bits.

1 Bit 1 Stelle – 0 oder 1
1 Byte 8 Bit
02

Bit

Ein Bit ist die kleinste Informationseinheit und kann nur zwei Werte annehmen: 0 oder 1. Das ist kein Zufall, sondern kommt direkt aus der Hardware: Ein Transistor kann nur unter niedriger oder hoher Spannung stehen. Diese beiden Zustände werden als 0 und 1 beschrieben.

niedrige Spannung 0
hohe Spannung 1
03

Byte

Acht Bits zusammen ergeben ein Byte. Ein Byte ist die übliche Grundeinheit, mit der ein Computer arbeitet. Weil jede der acht Stellen 0 oder 1 sein kann, lassen sich damit 28 = 256 verschiedene Kombinationen bilden – also die Werte von 0 bis 255.

Warum 256

Jede der 8 Stellen kann 0 oder 1 sein, das sind 2 × 2 × … × 2 (achtmal) = 256 Möglichkeiten. Ein einziges Bit mehr würde die Anzahl der Kombinationen verdoppeln.

04

Stellenwerte

Der Wert eines Bits hängt nicht nur davon ab, ob es 0 oder 1 ist, sondern auch davon, an welcher Stelle es steht. Jede Position hat einen festen Stellenwert.

Das kennst du schon aus dem Dezimalsystem: In der Zahl 375 ist die 3 nicht einfach „drei“, sondern drei Hunderter. Jede Stelle wird also mit ihrem Stellenwert multipliziert:

Dezimal Stellenwerte multiplizieren 
375 = 3·100 + 7·10 + 5·1

Allgemein beschreibt das die Positionswertformel: Jede Ziffer wird mit der Basis hoch ihrer Position multipliziert und alles aufsummiert.

N = n Σ i=0 di · bi
N
die zu berechnende Zahl
di
Ziffer an Position i
b
Basis des Zahlensystems
i
Index der Stelle (rechts beginnend bei 0)

Im Binärsystem funktioniert es genauso, nur sind die Stellenwerte Zweierpotenzen.

Um den Wert eines Bytes zu bestimmen, addierst du einfach die Stellenwerte aller Stellen, an denen eine 1 steht. Beispiel für das Byte 01001011:

Stellenwert 128 64 32 16 8 4 2 1
Bit 0 1 0 0 1 0 1 1

Wert = 64 + 8 + 2 + 1 = 75

Nur an den vier markierten Stellen steht eine 1. Zählt man ihre Stellenwerte zusammen (64 + 8 + 2 + 1), ergibt das den Wert 75.

Mit der Positionswertformel (Basis 2) ist das dieselbe Rechnung, nur ausgeschrieben (und so wirst du auch in Klausuren aufschreiben):

Binär Formel angewandt 
75 = 0·2⁷ + 1·2⁶ + 0·2⁵ + 0·2⁴ + 1·2³ + 0·2² + 1·2¹ + 1·2⁰
