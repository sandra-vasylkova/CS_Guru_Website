Python Grundlagen

Bedingungen.

Mit if, elif und else kann ein Programm Entscheidungen treffen.

01

Wozu dienen Bedingungen?

Mithilfe von Bedingungen trifft ein Programm Entscheidungen. Es prüft, ob eine Aussage wahr (True) oder falsch (False) ist, und führt anschließend den passenden Code aus.

Vergleichsoperatoren

== gleich
!= ungleich
> größer als
< kleiner als
>= größer oder gleich
<= kleiner oder gleich

Wichtig: = weist einer Variable einen Wert zu. == vergleicht zwei Werte. Vergleiche funktionieren übrigens nicht nur mit Zahlen, sondern auch mit Strings, etwa passwort == "geheim".

02

Die if-Bedingung

Beginne die Zeile mit if, schreibe danach die Bedingung und beende sie mit einem Doppelpunkt.

Python Eintritt prüfen 
alter = 17

if alter >= 18:
    print("Eintritt ist Erlaubt")

Das Programm prüft den Wert der Variable alter. Nur wenn der Wert mindestens 18 beträgt, wird „Eintritt ist Erlaubt“ ausgegeben.

Wichtig: Der Code nach dem Doppelpunkt muss eingerückt werden. Dafür kannst du die Tabulatortaste oder vier Leerzeichen verwenden. Dadurch kann das Programm erkennen, was es ausführen soll, wenn die Bedingung wahr ist.

03

Der else-Block

else wird ausgeführt, wenn die if-Bedingung falsch ist.

Python Alternative ausführen 
alter = 17

if alter >= 18:
    print("Eintritt ist Erlaubt")
else:
    print("Geh nach Hause")

Da alter in diesem Beispiel 17 ist, wird „Geh nach Hause“ ausgegeben.

04

Mehrere Bedingungen mit elif

elif bedeutet „else if“. Es prüft eine weitere Bedingung, wenn die vorherige Bedingung falsch war. Nur der erste passende Block wird ausgeführt.

Python Muttizettel prüfen 
alter = 17
hat_muttizettel = True

if alter >= 18:
    print("Eintritt ist Erlaubt")
elif hat_muttizettel:
    print("Eintritt ist Erlaubt")
else:
    print("Geh nach Hause")
05

Boolesche Operatoren

Mit and, or und not kannst du mehrere Prüfungen miteinander verbinden.

and Beide Aussagen müssen wahr sein.
or Mindestens eine Aussage muss wahr sein.
not Kehrt einen Wahrheitswert um.
Python Bedingungen verbinden 
alter = 17
hat_muttizettel = True

if alter >= 18 or hat_muttizettel:
    print("Eintritt ist Erlaubt")
else:
    print("Geh nach Hause")

Mit and müssen beide Bedingungen zutreffen, mit not wird ein Wahrheitswert umgekehrt.

Python and und not verwenden 
alter = 20
hat_ticket = True

if alter >= 18 and hat_ticket:
    print("Willkommen")

if not hat_ticket:
    print("Bitte zuerst ein Ticket kaufen")
06

Was wird ausgegeben?

Jetzt, wo du mit Theorie satt bist, lies beide Beispiele aus dem vorherigen Abschnitt noch einmal und überlege, was jeweils ausgegeben wird.

Beispiel mit or: Ausgabe „Eintritt ist Erlaubt“. alter ist zwar kleiner als 18, aber hat_muttizettel ist True.

Beispiel mit and und not: Ausgabe „Willkommen“. alter >= 18 und hat_ticket treffen beide zu. Die zweite Prüfung not hat_ticket ist False.

07

Bedingungen mit input

Zum Schluss verbessern wir unseren Türstehermodus mithilfe von input().

Python Alter direkt eingeben 
alter = int(input("Wie alt bist du? Nur die Wahrheit sagen! "))
hat_muttizettel = True

if alter >= 18 or hat_muttizettel:
    print("Eintritt ist Erlaubt")
else:
    print("Geh nach Hause")
