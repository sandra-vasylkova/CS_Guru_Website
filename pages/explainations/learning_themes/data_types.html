Python Grundlagen

Datentypen.

Verschiedene Datentypen ermöglichen es Python, deren Zweck zu unterscheiden.

01

Grundlagen

In Python gibt es vier grundlegende Datentypen: String (str), Integer (int), Float (float), Boolean (bool). Alle diese Datentypen können einer Variable zugewiesen werden.

Tipp: Mit der Funktion type() kannst du prüfen, zu welchem Datentyp ein Wert gehört.

Python Datentyp prüfen 
alter = 17
print(type(alter))
# Ausgabe: <class 'int'>
02

String

Zum Datentyp String gehören Texte, Buchstaben, Zahlen und Zeichen. Zur Darstellung eines Strings werden einfache oder doppelte Anführungszeichen verwendet.

Python String 
satz_doppel = "String mit doppelten Anführungszeichen"
satz_einzel = 'String mit einfachen Anführungszeichen'
03

Integer

Zum Datentyp Integer gehören ganze Zahlen. Es müssen keine Anführungszeichen verwendet werden.

Python Integer 
alter = 17
04

Float

Für Dezimalzahlen wird der Datentyp Float verwendet. Der Eintrag unterscheidet sich nicht von dem des Integers.

Python Float 
π = 3.14
05

Boolean

Der Datentyp Boolean kann nur zwei Werte haben: True oder False. Er wird verwendet, um Bedingungen und Aussagen zu überprüfen. Ein anschaulicheres Beispiel wird im Thema „Bedingungen“ gezeigt.

Python Boolean 
ist_schueler = True
06

Typumwandlung

Manchmal liegt ein Wert im falschen Datentyp vor und muss umgewandelt werden. Dafür gibt es integrierte Funktionen.

str() zu Text
int() zu ganzer Zahl
float() zu Kommazahl
Python Datentyp umwandeln 
alter_text = "17"
alter_zahl = int(alter_text)

print(alter_zahl + 1)
# Ausgabe: 18

Tipp: Das begegnet dir vor allem bei input(). Eine Eingabe wird immer als String zurückgegeben und muss für Berechnungen zuerst in eine Zahl umgewandelt werden. Mehr dazu im Thema „Print & Input“.
