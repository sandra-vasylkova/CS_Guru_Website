Python Grundlagen

Print & Input.

Mit print() gibst du Texte und Werte aus. Mit input() liest du Eingaben des Benutzers ein.

01

Print

print() ist eine der grundlegendsten Funktionen in Python. Mit ihr kann ein Programm Texte und Werte in der Konsole ausgeben. Sie kann mit allen üblichen Python-Datentypen verwendet werden.

Der Wert, der ausgegeben werden soll, schreibt man in klammern.

Python Strings, Zahlen und Variablen ausgeben 
print("Hello World")
print(6)

alter = 6
print(alter)
02

Mehrere Werte kombinieren

Mit print() können mehrere Werte gemeinsam ausgegeben werden. Dafür werden sie durch Kommas getrennt. Python fügt zwischen den Werten automatisch Leerzeichen ein.

Python Ausgabe mit Kommas 
print("Ich bin",6,"Jahre alt")

alter = 6
print("Ich bin",alter,"Jahre alt")
03

Ausgabe steuern: sep und end

print() hat zwei praktische Zusätze. Mit sep legst du fest, was zwischen den Werten steht, mit end, was am Ende der Ausgabe steht. Standardmäßig ist sep ein Leerzeichen und end ein Zeilenumbruch.

Python Trennzeichen und Zeilenende anpassen 
print("2025","07","23", sep="-")
# Ausgabe: 2025-07-23

print("Laden ...", end="")
print("fertig")
# Ausgabe: Laden ...fertig
04

f-Strings

Eine weitere Möglichkeit ist ein sogenannter f-String. Dabei wird vor den Anführungszeichen der Buchstabe f geschrieben. Variablen werden innerhalb des Strings in geschweifte Klammern gesetzt.

Python Variable in einen String einsetzen 
alter = 6
print(f"Ich bin {alter} Jahre alt")

# Ausgabe: Ich bin 6 Jahre alt
05

Input

input() ähnelt in ihrer Schreibweise der Funktion print(), hat aber eine andere Aufgabe. Mit input() kann ein Programm Eingaben des Benutzers einlesen. Die Funktion gibt die eingegebene Information zurück, damit sie beispielsweise in einer Variable gespeichert werden kann.

Python Benutzereingabe speichern 
name = input("Wie heißt du? ")
print(f"Dein Name ist {name}")

Zuerst wird die Frage angezeigt. Die Antwort des Benutzers wird von input() zurückgegeben und anschließend in der Variable name gespeichert.

Konsole Beispielausgabe 
Konsole: Wie heißt du?
Benutzer: Albert
Konsole: Dein Name ist Albert
06

Zahlen einlesen

Wichtig: input() liefert eine Eingabe zunächst immer als String zurück. Soll eine Zahl eingegeben werden, muss der Wert deshalb in den passenden Datentyp umgewandelt werden.

Python Datentyp der Eingabe umwandeln 
alter = int(input("Wie alt bist du? "))

pi_zahl = float(input("Wie lautet Pi auf drei Nachkommastellen? "))

Mit input() kann ein Programm Daten direkt vom Benutzer erhalten und anschließend weiterverarbeiten. Ein ausführlicheres Beispiel folgt im Thema „Bedingungen“.
