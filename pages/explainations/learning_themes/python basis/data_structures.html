05

Python Grundlagen

Datenstrukturen.

Eine Datenstruktur hält viele Werte auf einmal. Hier lernst du String, List, Tuple und Dictionary kennen.

01

Grundlagen

In Python gibt es vier grundlegende Datenstrukturen: String, Tuple, List und Dictionary. Der Unterschied zu einfachen Datentypen wie int oder bool: Die halten genau einen Wert. Eine Datenstruktur hält viele Werte auf einmal.

(Es gibt noch eine fünfte, das Set. Die schauen wir uns ganz am Ende kurz an.)

Alle vier teilen sich in veränderbare und unveränderbare auf. Modern ausgedrückt: mutable und immutable.

Unveränderbar String, Tuple
Veränderbar List, Dictionary

Aber was heißt das überhaupt? Hier ist ein Beispiel.

Python mutable vs. immutable 
text = "hallo"
text.upper()
print(text)          # hallo, nichts hat sich geändert!

zahlen = [3, 1, 2]
zahlen.sort()
print(zahlen)        # [1, 2, 3], hier schon

text.upper() verändert den String nicht, sondern baut einen neuen. Und der wird nicht gespeichert, weil du ihn nirgends aufgefangen hast. zahlen.sort() dagegen greift in die bestehende Liste hinein und sortiert sie direkt um.

Willst du das Ergebnis bei unveränderbaren Strukturen behalten, musst du es einer Variable zuweisen:

Python Ergebnis auffangen 
text = "hallo"
text = text.upper()
print(text)          # HALLO

Außerdem gilt für alle Strukturen außer dem Dictionary: Jedes Element hat seinen eigenen Index, es kennt sozusagen seinen Platz. Nimm dir ein Beispiel daran.

02

Funktion oder Methode?

Ich wusste den Unterschied bisher auch nicht, sei besser.

Python Funktion vs. Methode 
len(liste)          # Funktion: steht für sich, das Objekt kommt in die Klammern
liste.append(5)     # Methode: hängt über einen Punkt am Objekt dran

Eine Funktion ist eigenständig und funktioniert oft mit verschiedenen Typen. len() zählt Zeichen im String genauso wie Elemente in der Liste.

Eine Methode gehört zu einem bestimmten Typ. .append() gibt es nur bei Listen, .upper() nur bei Strings.

03

String

Jedes Zeichen eines Strings ist ein eigenes Element, das du über seinen Index abrufen kannst. Achte darauf: Indizes fangen in Python bei 0 an.

Python Index und Slicing 
name = "Albert"
print(name[2])       # b
print(name[0:3])     # Alb
print(name[4:])      # rt
print(name[-2:])     # rt
print(name[::2])     # Abr
print(name[::-1])    # treblA

Für einen Ausschnitt benutzt du Slicing in der Form sequenz[start:stop:schritt]. Der Stop-Wert ist dabei nicht mehr enthalten. Gibst du nur den Start an, geht es bis zum Ende. Negative Indizes zählen von hinten: -1 ist das letzte Zeichen. Ein negativer Schritt dreht das Wort um.

Und hier unterscheiden sich Strings von Listen: Auslesen darfst du jedes Zeichen, überschreiben leider nicht.

Python Unveränderbarkeit 
name = "Albert"
name[0] = "H"   # TypeError: 'str' object does not support item assignment

Willst du das Literal verändern, baust du dir einen neuen String zusammen:

Python Neuen String bauen 
name = "Albert"
name = "H" + name[1:]
print(name)          # Halbert

Nützliche Funktionen und Methoden für Strings

len(name) Anzahl der Zeichen 
name = "Albert"
print(len(name))   # 6
name.upper() in Großbuchstaben 
name = "Albert"
print(name.upper())   # ALBERT
name.lower() in Kleinbuchstaben 
name = "Albert"
print(name.lower())   # albert
name.strip() Leerzeichen am Rand entfernen 
name = "  Albert  "
print(name.strip())   # Albert
name.replace("A", "H") Zeichen ersetzen 
name = "Albert"
print(name.replace("A", "H"))   # Hlbert
name.split(" ") String in eine Liste zerlegen 
satz = "ich mag Python"
print(satz.split(" "))   # ['ich', 'mag', 'Python']
" ".join(["a", "b"]) Liste zu String verbinden 
teile = ["a", "b", "c"]
print(" ".join(teile))   # a b c
name.count("l") Vorkommen zählen 
name = "Albert"
print(name.count("l"))   # 1
name.find("b") Position finden 
name = "Albert"
print(name.find("b"))   # 2
"lbe" in name ist enthalten? 
name = "Albert"
print("lbe" in name)   # True
name.startswith("Al") beginnt mit? 
name = "Albert"
print(name.startswith("Al"))   # True

Denk dran: Keine davon verändert name selbst. Sie geben alle einen neuen String zurück.

Quick-Check

Gib einen Index oder Slice ein, der die gesuchte Ausgabe erzeugt.

name = "Albert"

Gesucht: rt

04

List

Eine Liste ist genau das, wonach es klingt: eine Sammlung verschiedener Elemente. Die Typen dürfen dabei bunt gemischt sein. Erkennbar ist sie an den eckigen Klammern.

Python Liste erstellen 
liste = ["Kugel", 2, "Apfel"]
einkaufsliste = ["Milch", "Brot", "C4", "Kekse"]

Es gibt außerdem die Funktion list(). Die verwandelt eine vorhandene Sammlung in eine Liste, zum Beispiel einen String in seine einzelnen Buchstaben:

Python list() 
print(list("Milch"))     # ['M', 'i', 'l', 'c', 'h']

Indizes und Slicing funktionieren genau wie beim String. Der Unterschied: Hier darfst du auch schreiben, nicht nur lesen.

Python Lesen und schreiben 
print(einkaufsliste[0])      # Milch
print(einkaufsliste[-1])     # Kekse
print(einkaufsliste[0:2])    # ['Milch', 'Brot']

einkaufsliste[0] = "Kaffee"
print(einkaufsliste)         # ['Kaffee', 'Brot', 'C4', 'Kekse']

Nützliche Funktionen und Methoden für Listen

Tippe auf eine Zeile für ein vollständiges Beispiel.

len(liste) Anzahl der Elemente 
liste = ["Milch", "Brot", "Kekse"]
print(len(liste))   # 3
liste.append("Käse") hinten anhängen 
liste = ["Milch", "Brot"]
liste.append("Käse")
print(liste)   # ['Milch', 'Brot', 'Käse']
liste.insert(0, "Tee") an Position einfügen 
liste = ["Milch", "Brot"]
liste.insert(0, "Tee")
print(liste)   # ['Tee', 'Milch', 'Brot']
liste.remove("Brot") Element mit Wert entfernen 
liste = ["Milch", "Brot", "Kekse"]
liste.remove("Brot")
print(liste)   # ['Milch', 'Kekse']
liste.pop() letztes entfernen und zurückgeben 
liste = ["Milch", "Brot", "Kekse"]
letztes = liste.pop()
print(letztes)   # Kekse
print(liste)     # ['Milch', 'Brot']
liste.pop(0) an Position entfernen 
liste = ["Milch", "Brot", "Kekse"]
erstes = liste.pop(0)
print(erstes)   # Milch
liste.index("Kekse") Position finden 
liste = ["Milch", "Brot", "Kekse"]
print(liste.index("Kekse"))   # 2
liste.count("Milch") Vorkommen zählen 
liste = ["Milch", "Brot", "Milch"]
print(liste.count("Milch"))   # 2
liste.sort() Liste selbst sortieren 
liste = [3, 1, 2]
liste.sort()
print(liste)   # [1, 2, 3]
sorted(liste) neue sortierte Liste, Original bleibt 
liste = [3, 1, 2]
print(sorted(liste))   # [1, 2, 3]
print(liste)           # [3, 1, 2]
liste.reverse() Reihenfolge umdrehen 
liste = ["Milch", "Brot", "Kekse"]
liste.reverse()
print(liste)   # ['Kekse', 'Brot', 'Milch']
liste.copy() echte Kopie erstellen 
liste = [1, 2, 3]
kopie = liste.copy()
kopie.append(4)
print(liste)   # [1, 2, 3]
sum([1, 2, 3]) Summe (nur Zahlen) 
print(sum([1, 2, 3]))   # 6
min([3, 1, 2]) kleinster Wert 
print(min([3, 1, 2]))   # 1
max([3, 1, 2]) größter Wert 
print(max([3, 1, 2]))   # 3
"Milch" in liste ist enthalten? 
liste = ["Milch", "Brot", "Kekse"]
print("Milch" in liste)   # True

Zwei Fallen, in die jeder einmal tappt

Erstens: .append() gibt nichts zurück. Schreib es ohne Zuweisung, sonst ist deine Liste weg. Das gilt für alle Methoden, die eine Liste direkt verändern: .sort(), .reverse(), .remove().

Python Falle 1 
einkaufsliste.append("Käse")
print(einkaufsliste)         # ['Milch', 'Brot', 'C4', 'Kekse', 'Käse']

Zweitens: b = a erzeugt keine Kopie.

Python Falle 2 
a = [1, 2, 3]
b = a
b.append(4)
print(a)                     # [1, 2, 3, 4]

Überraschung, a hat sich mitverändert. Es gibt nämlich gar keine zwei Listen, sondern eine Liste mit zwei Namen. Willst du wirklich eine zweite, nimm b = a.copy().

05

Tuple

Ein Tuple ist im Grunde eine Liste, die sich nichts mehr sagen lässt: gleiche Reihenfolge, gleiche Indizes, gleiches Slicing, nur eben unveränderbar. Statt eckiger Klammern nimmst du runde.

Python Tuple lesen 
punkt = (3, 5)
print(punkt[0])       # 3
print(punkt[-1])      # 5

punkt[0] = 7          # TypeError: 'tuple' object does not support item assignment

Und jetzt die berechtigte Frage: Und was soll ich bitte mit einer Liste, die ich nicht mal bearbeiten kann? Genau deswegen. Ein Tuple sagt jedem, der deinen Code liest (als ob es jemand außer deiner Lehrkraft wäre): „Diese Werte hängen voneinander ab und sollen sich nicht ändern.“ Koordinaten (3, 5), ein Farbwert (255, 0, 0), ein Datensatz ("Albert", 1879). Wenn dein Programm später versehentlich daran herumschreibt, kracht es sofort, statt still falsche Ergebnisse zu liefern.

Besonders praktisch ist das Unpacking. Du kannst mehrere Variablen auf einmal befüllen:

Python Unpacking 
punkt = (3, 5)
x, y = punkt
print(x)             # 3
print(y)             # 5

Links so viele Variablen wie rechts Elemente, und Python verteilt sie der Reihe nach.

Die klassische Falle

Ein Tuple mit nur einem Element: Die Klammern allein machen noch kein Tuple, das Komma macht es.

Python Ein-Element-Tuple 
einzel = (5)
print(type(einzel))          # <class 'int'>

einzel = (5,)
print(type(einzel))          # <class 'tuple'>

Funktionen und Methoden für Tuples

Die Liste ist kurz, was logisch ist: Alles, was verändert, fällt weg. Übrig bleiben:

Tippe auf eine Zeile für ein vollständiges Beispiel.

len(punkt) Anzahl der Elemente 
punkt = (3, 5)
print(len(punkt))   # 2
punkt.count(3) Vorkommen zählen 
punkt = (3, 5, 3)
print(punkt.count(3))   # 2
punkt.index(5) Position finden 
punkt = (3, 5)
print(punkt.index(5))   # 1
3 in punkt ist enthalten? 
punkt = (3, 5)
print(3 in punkt)   # True
tuple([1, 2, 3]) Liste zu Tuple 
print(tuple([1, 2, 3]))   # (1, 2, 3)
list((1, 2, 3)) Tuple zu Liste 
print(list((1, 2, 3)))   # [1, 2, 3]

Wenn du doch etwas ändern musst: Wandle das Tuple in eine Liste um, ändere es dort und mach wieder ein Tuple daraus.

06

Dictionary

Alle bisherigen Strukturen greifen über die Position zu. Beim Dictionary läuft es anders. Dort hat jeder Wert einen Schlüssel, über den du ihn ansprichst.

Deshalb auch der Name: Du schlägst nach wie im Wörterbuch (Ja, genau das ist die Übersetzung). Erkennbar ist es an den geschweiften Klammern. Drinnen stehen Paare aus Schlüssel und Wert, getrennt durch einen Doppelpunkt.

Python Dictionary erstellen 
user = {"name": "Albert", "alter": 25, "stadt": "Berlin"}
print(user["name"])          # Albert

Zahlen sind hier keine Positionen mehr, sondern ganz normale Schlüssel. user[0] funktioniert also nur dann, wenn du tatsächlich einen Schlüssel namens 0 angelegt hast. Neue Einträge legst du einfach durch Zuweisen an:

Python Einträge hinzufügen 
user["beruf"] = "Physiker"
user["alter"] = 26            # bestehender Schlüssel wird überschrieben
print(user)
# {'name': 'Albert', 'alter': 26, 'stadt': 'Berlin', 'beruf': 'Physiker'}

Ein Schlüssel kann also nur einmal vorkommen. Leider ist ein Service für Duplikate hier nicht vorgesehen. Schreibst du auf einen bestehenden, ersetzt du den alten Wert. Löschen geht über del oder .pop():

Python Einträge löschen 
del user["stadt"]
alter = user.pop("alter")     # entfernt und gibt den Wert zurück
Die häufigste Falle

Der KeyError, wenn ein Schlüssel fehlt.

Python KeyError vermeiden 
print(user["telefon"])                    # KeyError: 'telefon'

print(user.get("telefon"))                # None
print(user.get("telefon", "nicht bekannt")) # nicht bekannt

Wenn du nicht sicher bist, ob ein Schlüssel existiert, nimm .get(). Das stürzt nicht ab, sondern gibt None zurück, oder einen Ersatzwert, wenn du einen angibst. Und aufgepasst beim in: Es prüft die Schlüssel, nicht die Werte.

Python in prüft Schlüssel 
print("name" in user)         # True
print("Albert" in user)       # False

Verschachtelte Strukturen

Das ist der Punkt, an dem alles ernst wird. Echte Daten, etwa aus einer Datei oder Datenbank, sehen fast immer so aus: eine Liste voller Dictionaries.

Python Liste voller Dictionaries 
users = [
    {"name": "Anna", "alter": 20},
    {"name": "Ben", "alter": 34},
    {"name": "Sophie", "alter": 27},
]

print(users[1]["name"])      # Ben

Lies das von links nach rechts: users[1] holt das zweite Dictionary aus der Liste, ["name"] holt daraus den Wert zum Schlüssel name.

Nützliche Funktionen und Methoden für Dictionaries

Tippe auf eine Zeile für ein vollständiges Beispiel.

len(user) Anzahl der Paare 
user = {"name": "Albert", "alter": 25}
print(len(user))   # 2
user.get("name") Wert holen, ohne Absturz 
user = {"name": "Albert"}
print(user.get("name"))   # Albert
user.keys() alle Schlüssel 
user = {"name": "Albert", "alter": 25}
print(user.keys())   # dict_keys(['name', 'alter'])
user.values() alle Werte 
user = {"name": "Albert", "alter": 25}
print(user.values())   # dict_values(['Albert', 25])
user.items() alle Paare 
user = {"name": "Albert", "alter": 25}
print(user.items())   # dict_items([('name', 'Albert'), ('alter', 25)])
user.pop("alter") Eintrag entfernen und zurückgeben 
user = {"name": "Albert", "alter": 25}
alter = user.pop("alter")
print(alter)   # 25
print(user)    # {'name': 'Albert'}
user.update({"stadt": "Ulm"}) mehrere Einträge hinzufügen 
user = {"name": "Albert"}
user.update({"stadt": "Ulm"})
print(user)   # {'name': 'Albert', 'stadt': 'Ulm'}
user.clear() alles löschen 
user = {"name": "Albert", "alter": 25}
user.clear()
print(user)   # {}
"name" in user prüft die Schlüssel 
user = {"name": "Albert", "alter": 25}
print("name" in user)   # True

.keys(), .values() und .items() brauchst du vor allem dann, wenn du ein ganzes Dictionary durchgehen willst. Wie das geht, kommt im Thema Schleifen.

Hinweis für später

Als Schlüssel taugt nur, was unveränderbar ist, also Strings, Zahlen und Tuples. Eine Liste als Schlüssel wirft einen TypeError. Auch dafür sind Tuples also gut.

07

Set

Das Set ist die fünfte Struktur, die ich am Anfang unterschlagen habe. Es ist eine Sammlung ohne Reihenfolge und ohne Duplikate, jeder Wert kommt also genau einmal vor. Indizes gibt es deshalb nicht.

Am häufigsten begegnet es dir als Trick gegen doppelte Einträge:

Python Duplikate entfernen 
zahlen = [1, 2, 2, 3, 3, 3]
print(list(set(zahlen)))     # [1, 2, 3]

Für den Anfang reicht dir das.

08

Welche Struktur sollst du nehmen?

String

Für Text. Unveränderbar.

List

Mehrere Werte in fester Reihenfolge, die sich ändern dürfen. Dein Standardwerkzeug.

Tuple

Wenn sich nichts ändern soll. Für zusammengehörige Werte wie Koordinaten.

Dictionary

Wenn jeder Wert einen Namen braucht statt einer Nummer (KEINE WITZE HIER).

Set

Wenn jeder Wert nur einmal vorkommen darf.
