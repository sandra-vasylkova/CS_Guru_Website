Python Grundlagen

Funktionen.

Eine Funktion ist ein Codeblock, den du jederzeit aufrufen kannst. Hier schreibst du deine eigenen.

01

Was ist eine Funktion?

Funktionen sind mein Lieblingsthema aus den Python-Grundlagen. Eine Funktion ist ein Codeblock, den du jederzeit „aufrufen“ kannst. Übrigens kennst du ein paar von Pythons eingebauten Funktionen schon, zum Beispiel print() oder input(). In diesem Kapitel lernst du, eigene von Grund auf zu schreiben.

Eine Funktion ist grob gesagt eine Formel. Am Anfang legst du die Parameter und die Formel selbst fest, die danach auf die Eingabedaten (die Argumente) angewendet wird.

Python Eine eigene Funktion 
def addieren(a, b):
    return a + b

print(addieren(3, 5))

# Ausgabe: 8

Wie diese Funktion arbeitet: Zuerst wird mit def ihr Name festgelegt (addieren), und in den Klammern werden die Parameter definiert (a, b). Ein Parameter ist grob gesagt ein Platzhalter für einen zukünftigen Wert (das Argument).

Nach dem Doppelpunkt steht der Codeblock, der auf die Argumente angewendet wird. In diesem Fall wollen wir die Summe zweier Zahlen. Da die Funktion uns diese Zahl „zurückgeben“ soll, benutzen wir return.

Damit das Ergebnis in der Konsole erscheint, brauchst du die eingebaute Funktion print(), denn return gibt den Wert nur zurück, es zeigt ihn nicht an.

Merk dir

return gibt nicht nur einen Wert zurück, sondern beendet auch die Funktion. Alles, was danach steht, wird nicht mehr ausgeführt.

02

Ein größeres Beispiel

Bei diesem Beispiel fangen deine Gehirnzellen an zu arbeiten.

Python Durchschnitt berechnen 
def durchschnitt(zahlen):
    summe = sum(zahlen)
    ergebnis = summe / len(zahlen)
    return ergebnis

print(durchschnitt([2, 4, 6]))

# Ausgabe: 4.0

Was hier passiert: Zuerst werden Name und Parameter festgelegt. Dann kommt der Codeblock, in dem als Erstes die Variable summe definiert wird. Diese Variable nutzt die eingebaute Funktion sum(), die alle Zahlen im Argument aufsummiert. Danach speichert die Variable ergebnis die Summe geteilt durch die Anzahl der Zahlen, mithilfe der Funktion len(). Ganz am Ende wird ergebnis zurückgegeben.

Wie du richtig bemerkt hast, hat der Parameter keinen Typ. Trotzdem nimmt die Funktion eine Liste an. Ein Parameter ist nur ein Platzhalter, er legt fest, wie viele Argumente die Funktion braucht. In diesem Fall ist es eines. Den Typ kannst du aber trotzdem angeben:

Python Typangabe 
def durchschnitt(zahlen: list):
...

Und ich würde dir genau diese Schreibweise sehr empfehlen. Das macht deinen Code noch lesbarer.

03

print() oder return?

Manchmal brauchst du statt return ein print(), und so erkennst du das. Wenn du keine Berechnungen anstellen musst, sondern einfach nur einen bestimmten Text zusammen mit dem Argument ausgeben willst, brauchst du kein return.

Python Nur ausgeben 
def begruessung(name):
    print(f"Hallo, {name}!")

begruessung("Albert")

# Ausgabe: Hallo, Albert!

Die Aufgabe dieser Funktion besteht nur darin, Text in der Konsole auszugeben, deshalb ist die Wahl von print() hier absolut gerechtfertigt.

Aber so einfach ist das hier nicht. Eine Funktion ohne return gibt nichts zurück, genauer gesagt gibt sie None zurück. Deshalb kannst du so ein Ergebnis nicht in einer Variable speichern:

Python Der None-Haken 
gruss = begruessung("Albert")
print(gruss)

# Ausgabe:
# Hallo, Albert!
# None

Die erste Zeile ist das print() innerhalb der Funktion selbst. Und das None ist das, was die Funktion zurückgegeben hat, beziehungsweise eben nicht zurückgegeben hat.

Merk dir

print() zeigt, return gibt zurück. Wenn du das Ergebnis weiterverwenden willst, brauchst du return.

Außerdem kannst du eine Funktion ganz ohne Parameter erstellen.

Python Ohne Parameter 
def willkommen():
    print("Hallo und willkommen zu meiner Webseite!")

willkommen()

# Ausgabe: Hallo und willkommen zu meiner Webseite!

Man könnte auch einfach ein normales print() verwenden, aber das ist Geschmackssache. Wenn die Begrüßung nur einmal vorkommt, ist die Funktion tatsächlich überflüssig. Aber wenn sie mehrmals erscheinen soll, ist die Funktion definitiv die bessere Wahl.

04

Hilfsfunktionen und main()

Wenn du mehrere Funktionen hast, die zusammen benutzt werden sollen, werden sie zu sogenannten Hilfsfunktionen. Die werden später alle in der Hauptfunktion main() zusammengeführt.

Python Alles in main() zusammenführen 
def begruessung(name):
    print(f"Hallo, {name}!")

def durchschnitt(zahlen):
    return sum(zahlen) / len(zahlen)

def main():
    begruessung("Albert")
    noten = [2, 4, 6]
    schnitt = durchschnitt(noten)
    print(f"Dein Durchschnitt ist {schnitt}")

main()

# Ausgabe:
# Hallo, Albert!
# Dein Durchschnitt ist 4.0

Wie du siehst, sind beide Hilfsfunktionen die Bauteile eines Konstrukteurs, der in der Hauptfunktion zusammengebaut wird. So sieht dein Code ordentlich und verständlich aus.

Profi-Tipp

Wenn du der Liebling deiner Lehrkraft werden willst, benutz diese Schreibweise immer (fast).
