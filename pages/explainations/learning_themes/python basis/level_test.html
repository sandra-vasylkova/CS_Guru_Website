Variablen

1 Welche Zeile speichert den Wert 17 in der Variablen alter?

= ist der Zuweisungsoperator: links der Name, rechts der Wert. == vergleicht nur.

2 Welcher Variablenname ist ungültig?

Ein Variablenname darf nicht mit einer Ziffer beginnen – Buchstaben und _ sind als erstes Zeichen erlaubt.

3 Was gibt dieser Code aus? 

punkte = 10
punkte = punkte + 5
print(punkte)

Rechts wird zuerst gerechnet (10 + 5), das Ergebnis überschreibt danach den alten Wert.

4 Wie schreibt man in Python üblicherweise eine Konstante?

Python kennt kein echtes Konstanten-Schlüsselwort. Man signalisiert per Konvention mit GROSSBUCHSTABEN, dass ein Wert nicht verändert werden soll.

2

Datentypen

5 Welchen Datentyp hat der Wert 3.0?

Sobald ein Punkt im Spiel ist, handelt es sich um eine Kommazahl – also float, auch bei 3.0.

6 Was gibt dieser Code aus? 

print(type("17"))

Die Anführungszeichen machen aus der Zahl einen Text. Nicht der Inhalt entscheidet über den Typ, sondern die Schreibweise.

7 Was ist das Ergebnis von int("7") + 3?

int() wandelt den Text "7" in die Zahl 7 um – danach wird normal addiert.

8 Welchen Datentyp liefert die Division 10 / 2?

/ liefert in Python immer einen float. Für eine ganzzahlige Division gibt es //.

3

Print & Input

9 Welchen Datentyp liefert input()?

Auch 42 kommt als Text "42" an – deshalb muss man vor dem Rechnen mit int() oder float() umwandeln.

10 Was gibt dieser Code aus? 

print("Hallo", "Welt")

Mehrere Werte in print() werden standardmäßig durch ein Leerzeichen getrennt. Ändern lässt sich das mit sep=.

11 Wie liest man eine Eingabe direkt als ganze Zahl ein?

Erst wird eingelesen, dann umgewandelt: die innere Klammer input() läuft zuerst, das Ergebnis geht an int().

12 Was gibt dieser Code aus? 

name = "Ada"
print(f"Hi {name}!")

Das f vor dem String macht daraus einen f-String: Alles in geschweiften Klammern wird durch den Wert der Variablen ersetzt.

4

Bedingungen

13 Welcher Operator prüft auf Gleichheit?

Ein einzelnes = weist zu, ein doppeltes == vergleicht und liefert True oder False.

14 Was gibt dieser Code aus? 

x = 5
if x > 10:
    print("gross")
elif x > 3:
    print("mittel")
else:
    print("klein")

Python prüft von oben nach unten und führt nur den ersten zutreffenden Zweig aus. Danach überspringt es den Rest der Kette.

15 Was ergibt der Ausdruck True and not False?

not False ergibt True, und True and True ist wieder True.

16 Was passiert, wenn keine Bedingung zutrifft und es kein else gibt?

Ein else ist optional. Ohne passenden Zweig wird der ganze Block einfach übersprungen.

5

Datenstrukturen

17 Was gibt dieser Code aus? 

zahlen = [10, 20, 30, 40]
print(zahlen[1])

Indizes starten bei 0. Index 1 ist also das zweite Element.

18 Was ergibt "Python"[-2]?

Negative Indizes zählen von hinten: -1 ist das letzte Zeichen (n), -2 das vorletzte.

19 Welche Datenstruktur ist unveränderlich?

Ein Tuple (1, 2, 3) lässt sich nach dem Erstellen nicht mehr ändern – genau das macht es sicher für feste Wertegruppen.

20 Wie liest man den Namen aus diesem Dictionary? 

person = {"name": "Ada", "alter": 36}

In einem Dictionary greift man über den Schlüssel in eckigen Klammern zu, nicht über eine Position.

6

Schleifen

21 Wie oft läuft der Rumpf von for i in range(3):?

range(3) liefert 0, 1, 2 – drei Werte, also drei Durchläufe.

22 Was gibt dieser Code aus? 

for i in range(1, 4):
    print(i, end=" ")

Der Startwert gehört dazu, der Endwert nicht: range(1, 4) ist 1, 2, 3.

23 Welches Schlüsselwort bricht eine Schleife sofort komplett ab?

break verlässt die Schleife ganz. continue überspringt nur den aktuellen Durchlauf.

24 Wann nimmt man eine while-Schleife?

while läuft, solange eine Bedingung wahr ist – ideal z. B. für Eingaben, die so lange wiederholt werden, bis sie stimmen.

7

Funktionen

25 Wie definiert man in Python eine Funktion?

Das Schlüsselwort heißt def, danach folgen Name, Klammern und ein Doppelpunkt.

26 Was gibt dieser Code aus? 

def verdopple(x):
    return x * 2

print(verdopple(4))

return gibt den Wert an die aufrufende Stelle zurück – dort landet also 8 im print().

27 Was liefert eine Funktion ohne return zurück?

Ohne return gibt Python automatisch None zurück – die Funktion tut etwas, liefert aber kein Ergebnis.

28 Was gibt dieser Code aus? 

def begruesse(name, gruss="Hallo"):
    print(gruss, name)

begruesse("Ada")

gruss hat einen Standardwert. Wird beim Aufruf nichts übergeben, springt automatisch "Hallo" ein.
