Python Grundlagen

Schleifen.

Mit einer Schleife schreibst du einen Codeblock einmal und wiederholst ihn beliebig oft.

01

Die for-Schleife

Schleifen sind praktisch, weil du einen Codeblock einmal schreibst und ihn dann beliebig oft wiederholen kannst. Statt dieselbe Zeile zehnmal zu tippen, geh lieber raus und fass mal Gras an. Glaub mir.

In Python gibt es zwei Arten von Schleifen: for und while. Die for-Schleife könnte man einen Iterator nennen. Mit ihr kannst du zum Beispiel jedes Element einer Liste durchgehen.

Python Liste durchgehen 
lebensziele = ["Schule beenden", "Programmieren", "Python lernen", "Wasser trinken"]

for ziel in lebensziele:
    print(ziel)

# Ausgabe:
# Schule beenden
# Programmieren
# Python lernen
# Wasser trinken

Kurz übersetzt: Für jedes Ziel aus der Liste lebensziele wird das Ziel ausgegeben. ziel ist eine Variable, der bei jedem Durchgang ein neuer Wert aus der Liste zugewiesen wird, bis die Elemente ausgehen. Du kannst sie nennen, wie du willst, meinetwegen auch Shrek, aber dann wünsche ich deinem Lehrer schon mal viel Kraft und Geduld.

Also: Nimm dir den Rat aus dem ersten Thema zu vernünftigen Variablennamen zu Herzen und mach dir und allen anderen das Leben leichter.

Wichtig

Wie schon bei den Bedingungen brauchst du einen Doppelpunkt und eine Einrückung von vier Leerzeichen. Alles, was eingerückt ist, wird bei jedem Durchgang wiederholt. Code ohne Einrückung läuft erst weiter, nachdem die Schleife beendet ist. Und denk dran: Python liest den Code von oben nach unten.

Da ein String genau wie eine Liste eine Datenstruktur ist, funktioniert die Iteration auch mit ihm.

Python String durchgehen 
fach = "Mathe"

for char in fach:
    print(char)

# Ausgabe:
# M
# a
# t
# h
# e

Falls du dich fragst: char ist die Abkürzung für character 😉

02

Die Funktion range()

Das ist wohl die meistgenutzte Funktion in Verbindung mit einer for-Schleife. Wenn du eine Folge von Zahlen brauchst (ich frag gar nicht erst, wozu) oder eine bestimmte Aktion n-mal wiederholen willst, ist range() genau das Richtige für dich.

Python range(5) 
for i in range(5):
    print(i)

# Ausgabe:
# 0
# 1
# 2
# 3
# 4

range(5) erzeugt die Zahlen von 0 bis 4. Die angegebene Endzahl 5 ist also nicht mehr enthalten. Da bei 0 angefangen wird, entstehen trotzdem genau fünf Zahlen.

Wenn du auch die Zahl 5 ausgeben möchtest, erhöhst du das Ende um 1.

Python Ende einschließen 
n = 5

for i in range(n + 1):
    print(i)

# Ausgabe:
# 0
# 1
# 2
# 3
# 4
# 5

So ist die in der Variable gespeicherte Zahl ebenfalls enthalten. Du kannst außerdem einen Start- und Endpunkt angeben: range(n, k) läuft von n bis k, wobei k selbst nicht mehr enthalten ist.

Python Bereich festlegen 
for i in range(2, 5):
    print(i)

# Ausgabe:
# 2
# 3
# 4

Mit einem dritten Wert bestimmst du die Schrittweite: range(n, k, m).

Python Schrittweite 
for i in range(0, 10, 2):
    print(i)

# Ausgabe:
# 0
# 2
# 4
# 6
# 8
Warum i und _?

i wird oft als Abkürzung für index verwendet. Bei kurzen Schleifen hat sich dieser Name einfach eingebürgert. Und wenn du nur markieren willst, dass eine Aktion mehrmals ausgeführt wird, nimm den Unterstrich _.

Python Nur wiederholen 
lieblingsort = "Schule"

for _ in range(3):
    print(lieblingsort)

# Ausgabe:
# Schule
# Schule
# Schule

Hier steht der Unterstrich nur, damit die Schleife läuft, nicht weil die Variable selbst wichtig wäre.

03

enumerate()

Jetzt wird's schon interessanter. Sagen wir, du baust ein Alphabet und willst wissen, welcher Buchstabe an welcher Stelle kommt. Wie du weißt, hat jedes Element einer Liste seinen eigenen Index. Mit enumerate() gibt Python dir Index und Element zugleich.

Python Index und Element 
alphabet = ["a", "b", "c", "d", "e", "f", "g", "h", "i", "j", "k", "l", "m", "n", "o", "p", "q", "r", "s", "t", "u", "v", "w", "x", "y", "z"]

for index, letter in enumerate(alphabet):
    print(index, letter)

# Ausgabe:
# 0 a
# 1 b
# 2 c
# ...

Aber das ist doch nicht der nullte, sondern der erste Buchstabe des Alphabets, sagst du, und damit hast du recht. Mit start=1 lässt du die Zählung bei 1 beginnen:

Python Zählung ab 1 
for index, letter in enumerate(alphabet, start=1):
    print(f"{index}. {letter}")

# Ausgabe:
# 1. a
# 2. b
# 3. c
# ...

Mit dem f-String haben wir das Ganze auch noch hübsch gemacht.

04

break und continue

Mit break und continue steuerst du den Ablauf einer Schleife noch genauer.

break beendet die Schleife sofort. Nehmen wir an, du brauchst alle Buchstaben bis m:

Python break 
for index, letter in enumerate(alphabet, start=1):
    if letter == "m":
        print(f"{letter} ist der {index}. Buchstabe im Alphabet")
        break
    print(letter)

# Ausgabe:
# a
# b
# c
# ...
# k
# l
# m ist der 13. Buchstabe im Alphabet

Die restlichen Buchstaben werden gar nicht erst durchgegangen, weil die Schleife ihr Ziel erreicht hat. Sei wie die Schleife, erreiche deine Ziele!

continue überspringt ein bestimmtes Element und macht ohne anzuhalten mit der Schleife weiter:

Python continue 
for i in range(5):
    if i == 2:
        continue
    print(i)

# Ausgabe:
# 0
# 1
# 3
# 4
05

Die while-Schleife

Hier ist im Vergleich zu for alles ganz einfach. while wiederholt einen Codeblock so lange, wie eine Bedingung wahr ist. Im Grunde ist das der gute alte if, der sich immer und immer wieder wiederholt.

Python while-Schleife 
count = 0

while count < 5:
    print(count)
    count += 1

# Ausgabe:
# 0
# 1
# 2
# 3
# 4

Was hier passiert: Anfangs ist count gleich 0. Vor jedem Durchgang prüft while, ob count < 5 wahr ist. Danach wird count ausgegeben und durch count += 1 um 1 erhöht. Sobald count den Wert 5 erreicht, ist die Bedingung falsch und die Schleife endet.

06

Endlosschleife

Die Zeile count += 1 ist nichts anderes als count = count + 1. Das ist hier das entscheidende Detail, denn ohne sie bleibt die Bedingung in jeder Runde wahr. count bleibt dann 0, was klar kleiner als 5 ist, und die Schleife spammt deine Konsole mit Nullen zu. Ich rate dir, das nicht auszuprobieren, sondern mir einfach aufs Wort zu glauben.

Notausgang

Falls du so eine Schleife doch startest: Mit Strg + C (auf dem Mac Control + C) brichst du sie ab.

Trotzdem ist eine Endlosschleife manchmal sogar nötig. Bei while True benutzt man häufig break, sobald die gewünschte Bedingung erfüllt ist. Als Beispiel bauen wir ein Mini-Spiel „Zahl erraten“:

Python Mini-Spiel „Zahl erraten“ 
zahl = 5

while True:
    versuch = int(input("Rate die Zahl: "))
    if versuch == zahl:
        print("Richtig!")
        break
    elif versuch < zahl:
        print("höher")
    else:
        print("niedriger")

So fragt die Konsole den Benutzer so lange nach einer Zahl, bis er sie errät. An diesem Beispiel kannst du dich gleich auf all die vorherigen Themen testen.

Für alle Fälle lasse ich dir noch eine ausführliche Erklärung da, die du garantiert nicht brauchen wirst 😀

zahl = 5 legt die geheime Zahl fest. while True startet eine Schleife, die zunächst endlos läuft.

In jedem Durchgang liest int(input(...)) eine Eingabe ein und wandelt sie sofort in eine ganze Zahl um. Dann wird verglichen: Ist versuch == zahl, erscheint „Richtig!“ und break beendet die Schleife.

Ist der Versuch kleiner als die Zahl, kommt der Hinweis „höher“, andernfalls „niedriger“. So wiederholt sich alles, bis die richtige Zahl getroffen ist.

07

Welche Schleife brauche ich?

for

dann, wenn die Anzahl der Wiederholungen und der Endpunkt bekannt sind. Das heißt, du weißt, was du durchgehst und wie oft du es durchgehst.

while

wähle, wenn du keinen Schimmer hast, wie oft du den Code wiederholen musst, aber den Endpunkt genau kennst.

Kleines Geheimnis

In den meisten Fällen brauchst du for. Also wenn du unsicher bist, for hilft dir immer weiter.
