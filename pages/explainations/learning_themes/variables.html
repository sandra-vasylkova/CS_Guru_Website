01

Python Grundlagen

Variablen.

Variablen speichern Werte, damit du sie später im Programm verwenden oder verändern kannst.

01

Was ist eine Variable?

Eine Variable ist ein sogenannter Platzhalter. Das bedeutet: Ein Wort oder eine Bezeichnung speichert einen Wert. Für die Zuweisung wird der Operator = verwendet.

Python Variable und Wert 
alter = 17
02

Was ist ein Literal?

Ein Wert, der direkt im Code steht, wird Literal genannt. Im Beispiel ist 17 das Literal und alter die Variable.

Variable alter
Literal 17
03

Passende Namen verwenden

Für ein besseres Verständnis des Codes solltest du Variablen passende Namen geben. Dadurch ist sofort erkennbar, welchen Wert sie speichern.

Guter Name 
alter = 17
Unklarer Name 
x = 17

In Python werden Variablennamen normalerweise kleingeschrieben. Wenn du mehrere Wörter verbinden möchtest, trenne diese mit einem Unterstrich.

Python Mehrteiliger Variablenname 
aktuelle_punktzahl = 10
04

Regeln für Variablennamen

Ein Variablenname darf nur aus Buchstaben, Zahlen und Unterstrichen bestehen, aber nicht mit einer Zahl beginnen. Leerzeichen sind nicht erlaubt, nutze stattdessen einen Unterstrich.

Erlaubt 
mein_alter = 17
Nicht erlaubt 
2alter = 17

Achtung: Groß- und Kleinschreibung zählt. alter und Alter sind zwei verschiedene Variablen. Auch reservierte Wörter wie if oder True sind nicht erlaubt.

05

Werte verändern

Der Wert einer Variable kann im späteren Code neu zugewiesen werden. Dabei wird der alte Wert durch den neuen ersetzt.

Python Neue Wertzuweisung 
aktuelle_punktzahl = 10

# später im Programm
aktuelle_punktzahl = 15

Die Zeile mit # ist ein Kommentar: Alles hinter der Raute ist nur für Menschen gedacht und wird von Python ignoriert. So kannst du deinen Code erklären.

Ein neuer Wert darf sich auch aus dem alten ergeben. Python berechnet dabei zuerst die rechte Seite und speichert das Ergebnis anschließend wieder in der Variable.

Python Wert weiterverwenden 
aktuelle_punktzahl = 10
aktuelle_punktzahl = aktuelle_punktzahl + 5

print(aktuelle_punktzahl)
# Ausgabe: 15

Für diesen häufigen Fall gibt es eine Kurzschreibweise. Genauso funktionieren -=, *= und /=.

Python Kurzschreibweise mit += 
# kurz für: aktuelle_punktzahl = aktuelle_punktzahl + 5
aktuelle_punktzahl += 5
06

Konstanten

Um eine bestimmte Variable im weiteren Code als unveränderlich zu kennzeichnen, werden in Python Großbuchstaben verwendet.

Python Konstante 
ALTER = 17
07

Tipp

Verwende Variablen, wenn ein Wert eine bestimmte Bedeutung hat, später erneut verwendet oder verändert werden soll. Anfangs mag das manchmal überflüssig erscheinen, aber wenn deine Projekte an Umfang zunehmen, wirst du feststellen, dass sinnvoll benannte Variablen die Lesbarkeit deines Codes erheblich verbessern.
